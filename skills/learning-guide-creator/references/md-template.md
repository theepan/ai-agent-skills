# Markdown Template Reference

This is the formatting reference for learning guide documents. Follow these conventions for consistent, professional output.

## Document Structure

Start every guide with a front matter header, then table of contents, then chapters:

```
# [Topic Title]
**A Beginner's Guide to Understanding [Topic]**
*[Month Year]*

---

*This guide is written for [describe target audience]. No prior knowledge of [topic] is assumed.*

---

## Table of Contents
- [Chapter 1: Title](#chapter-1-title)
- [Chapter 2: Title](#chapter-2-title)
...

---
```

## Chapter Format

Each chapter follows this pattern:

```
## Chapter 1: [Title]

*What you'll learn: [1-2 sentence overview of the chapter]*

### 1.1 [Section Title]

[Body text...]

### 1.2 [Section Title]

[Body text...]

---

**Key Takeaways**
- [Point 1]
- [Point 2]
- [Point 3]
```

## Callout Boxes

Use blockquotes with bold labels for callouts:

> **Tip:** [Practical advice here]

> **Warning:** [Critical information or common mistake here]

> **Example:** [Real-world scenario here]

## Tables

Use standard Markdown tables for comparisons and structured data:

```
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data     | Data     | Data     |
```

## Glossary Format

Use a table for the glossary chapter:

```
## Glossary of Terms

| Term | Definition |
|------|-----------|
| Term 1 | Plain English definition |
| Term 2 | Plain English definition |
```

## References Format

```
## References & Further Reading

1. [Source Title](URL) — Brief description
2. [Source Title](URL) — Brief description
```

## Formatting Rules

- Use `#` for the document title only
- Use `##` for chapter titles
- Use `###` for section headings within chapters
- Use `---` horizontal rules to separate chapters and major sections
- Use **bold** for key terms on first introduction
- Use *italics* for the "What you'll learn" opener and emphasis
- Use bullet lists (`-`) for Key Takeaways and general lists
- Use numbered lists (`1.`) for sequential steps or ranked items
- Keep paragraphs focused — one idea per paragraph, with a blank line between them
